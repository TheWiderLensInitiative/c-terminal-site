# C Terminal website

The site for [C Terminal](https://github.com/TheWiderLensInitiative/c-terminal), your PC's terminal on your phone
over Tailscale: https://cterminal.thewiderlens.info

Static HTML, deployed by Vercel on every push to `main`.

- `index.html`: the home page
- `privacy.html`: generated from `docs/PRIVACY.md` in the C Terminal repo; keep them the same
- `assets/`: logo and icon (from the app's `brand/`), Montserrat (OFL), screenshots (demo project), social card
